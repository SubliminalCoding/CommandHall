# Contributing

Bug reports and clear reproduction cases are welcome. Before opening an issue:

1. reproduce the problem on the latest release or current `main`;
2. run `scripts/ci.sh` when the problem involves a source change;
3. remove credentials, private prompts, local paths, and workspace data;
4. include the macOS version, CommandHall version, and relevant provider CLI version.

Pull requests may be used to illustrate a proposed fix, but they are not merged directly. The maintainer independently reviews the idea and decides whether and how to implement it. This keeps authorship, release responsibility, and security review under one owner.

Use GitHub's private vulnerability reporting instead of a public issue for security-sensitive findings. See [SECURITY.md](SECURITY.md).
